# Icon Assets

Deze map bevat de iconenset voor de storefront. De belangrijkste iconen worden geladen via `components/ui/Icon.tsx`, zodat knoppen, navigatie, winkelwagen en checkout dezelfde visuele taal gebruiken.

Huidige toegewezen iconen:

- Navigatie: `shopping-bag.png`, `search-location.png`, `briefcase.png`, `user-support.png`, `user-account-support.png`
- Winkelwagen en checkout: `shopping-cart-1.png`, `credit-card.png`, `delivery-truck.png`, `document-page-1.png`, `document-checkmark.png`
- Formulieren en acties: `search-magnifier.png`, `login-enter.png`, `user-plus.png`, `price-tag.png`, `refresh-arrows.png`, `trash-bin.png`, `arrow-right-1.png`
- Merk/vertrouwen: `leaf-1.png`, `shield-1.png`

Nieuwe iconen kunnen later onder dezelfde naamgevingsstijl worden toegevoegd en via `<Icon name="..." />` worden gebruikt.
